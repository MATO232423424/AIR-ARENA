# AIR-ARENA | FiveM Custom Map

Custom floating arena for FiveM featuring unique ramp structures and a clean design. Perfect for PvP servers, events and custom gameplay.

## ✨ Features

- Custom floating arena
- Unique ramp structures
- Custom map assets
- Designed for FiveM
- Suitable for PvP and custom events
- Floating arena located high above the map

## 📦 Requirements

- FiveM server
- Grand Theft Auto V

## ⚙️ Installation

1. Download or clone this repository
2. Drag the `AIR-ARENA` resource folder into your server's `resources` folder
3. Add `ensure AIR-ARENA` to your `server.cfg`
4. Restart your server

## 📍 Arena Location

The arena is located high in the air at the following coordinates:

`-1779.3158, -3796.2678, 617.0942, 31.3200`

Use these coordinates to teleport to the arena.
